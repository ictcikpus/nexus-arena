# NEXUS ARENA GDD (MVP)

- Genre: 3D multiplayer obstacle racing.
- Platform: browser PC dan HP.
- Room: maksimum delapan pemain.
- Match: pemain harus siap, countdown tiga detik, lari melewati rintangan/checkpoint, finis atau timer berakhir.
- Movement: arah gerak, lompat, sprint; server melakukan simulasi otoritatif.
- Checkpoints: dua area checkpoint; jatuh memicu respawn dan penalti waktu.
- Result: pemain finis diberi waktu finis berdasarkan elapsed time + penalti. Jika waktu habis, server menyimpan progres yang tercapai.
- MVP exclusions: akun permanen, database profil eksternal, voice chat, inventori kompleks, transaksi, dan leaderboard global.
- Visual: arena stylized prosedural, tidak membutuhkan aset berbayar untuk mulai bermain.
